# Tomo English Phonics d & t

Static Vercel-ready site generated from the 6-page phonics PDF.

## Features
- 6-page responsive viewer
- Audio playback buttons on page 3 and page 5
- Only one audio clip plays at a time
- Uses existing word recordings for the current d/t lesson
- No audio attached to isolated /d/ or /t/ buttons
